# Obsidian Studio — Portfolio

Personal portfolio of Bilal Ansari (Obsidian Studio): an interactive desk scene with an openable book, working iPod and intro boot sequence.

Live: https://ansaribilal10976-lang.github.io/deskfolio/

## Stack
React 19, Vite, TypeScript. Deployed to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.

## Develop
```
npm ci
npm run dev
npm run build
```
